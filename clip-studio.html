สูตรของฉัน

สูตรที่บันทึกจากหน้า “สร้าง Prompt” เก็บในเบราว์เซอร์เครื่องนี้ ส่งออกเก็บไว้หรือย้ายไปอีกเครื่องได้

ตรวจก่อนโพสต์ 20 ด่าน

ชุดตัดต่อรันให้อัตโนมัติหลังเรนเดอร์ ไม่ผ่าน = ต้องแก้ก่อนโพสต์ เตือน = ดูแล้วตัดสินใจเอง

    ทำอะไรให้เองบ้าง

    • ตัดช่วงเงียบ ตัด “เอ่อ / อ่า / อืม” และคำที่พูดซ้ำติดกัน
    • ซับไทยขึ้นทีละคำตามเสียง ตัดบรรทัดตามคำ ไม่เกิน 2 บรรทัด ไม่ฉีกคำกลางคำ
    • คำสำคัญ (ตัวเศษ ตัวส่วน ตัวเลข ฯลฯ) เด้งและเปลี่ยนสี
    • Hook 3 วินาทีแรก จากประโยคเปิดของคลิป (หรือพิมพ์เอง)
    • B-roll ตามคำที่พูด: ภาพในโฟลเดอร์ตั้งชื่อตามคำ และสร้างภาพวงกลมเศษส่วนให้เองเมื่อพูดถึง 1/2 หรือ “หนึ่งส่วนสอง”
    • แบ่งจอ ภาพประกอบบน คนพูดล่าง สลับกับคนพูดเต็มจอในคลิปเดียว
    • แบ่งไฟล์ยาว/ไลฟ์เป็นคลิปสั้นตามช่วงเงียบ ไม่ตัดกลางประโยค
    • ปรับความดังเสียง (-16 คลิปสอน / -14 คลิปสั้น) และตรวจ 20 ด่าน

    ข้อจำกัดที่ควรรู้

    • ถอดเสียงภาษาไทยด้วย Whisper ในเครื่อง ยังพลาดได้ ควรเปิดซับดูก่อนโพสต์
    • Whisper บางครั้งไม่ถอด “เอ่อ” จึงอาศัยการตัดช่วงเงียบเป็นหลัก
    • เครื่องไม่มีการ์ดจอ ถอดเสียงจะช้า (คลิป 15 นาที ราว 10-20 นาที)
    • B-roll จับคู่ตามชื่อไฟล์กับคำที่พูดเท่านั้น ไม่ได้เข้าใจภาพรวมของเรื่อง
    • ยังไม่มีเสียงพากย์ AI และไม่สร้างคลิป motion จากหัวข้อล้วน ๆ

    คำสั่งที่ใช้บ่อย

    โฟลเดอร์ clip-studio อยู่ในเครื่องครู (ไม่ได้อยู่บน GitHub)

    ตัดต่อคลิปสอน 1 คลิป (ซับ + ตรวจ 20 ด่าน)
    python clipstudio.py run D-01-raw.mp4 -o out/D-01.mp4 --preset lesson
    คลิปสั้น แนวตั้ง แบ่งจอบน-ล่าง ซับเด้ง
    python clipstudio.py split slide.mp4 face.mp4 -o out/split.mp4
python clipstudio.py run out/split.mp4 -o out/S-01.mp4 --preset short --motion pop
    ไฟล์ยาว/ไลฟ์ → คลิปสั้นหลายคลิป
    python clipstudio.py shorts LONG.mp4 -o out --min 25 --max 55 --process
    ตรวจอย่างเดียว / สรุปสถานะทุกคลิปเข้าเดชบอร์ดนี้
    python clipstudio.py qc out/D-01.mp4
python clipstudio.py status out/

    คำสั่ง status จะสร้าง clips_status.json นำเข้าที่แท็บ “ติดตามคลิป” แล้วคลิปที่ผ่านตรวจจะถูกมาร์กให้
